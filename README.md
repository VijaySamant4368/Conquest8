# Pirate Hunt – Goldbeard Trail

A no-backend browser-extension treasure hunt built around your hint chain.

## What it does

- Opens with **Page 1: Bon Voyage** on a local extension page.
- Injects pirate-style hint panels onto the real web pages in your flow.
- Adds the **"second option dekho"** helper on the Shepheard/Shepherd Creek Google results page.
- Inserts a **Goldbeard** image card on the Find a Grave page.
- Turns the **Monocular** wiki image into the final clickable reveal.

## Flow covered

1. Bon Voyage
2. Letter of Marque (Wikipedia)
3. Pirate code (Wikipedia)
4. Moon phase tracker (timeanddate)
5. Deadman's Island / coordinates (Google Maps or Google Search)
6. Shepherds Creek (TSHA)
7. Shepherds Creek Cemetery (Find a Grave)
8. Monocular (Wikipedia)
9. Final pirate island reveal

## Install

### Chrome / Brave / Edge

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. Click **Load unpacked**
4. Select this folder

### Firefox

1. Open `about:debugging#/runtime/this-firefox`
2. Click **Load Temporary Add-on**
3. Select the `manifest.json` file from this folder

## Start

Click the extension icon, then choose **Open Bon Voyage**.
